1 Вступ до NLP

Natural Language Processing (обробка природної мови) — це як комп’ютер «розуміє» текст. Ми розберемо класичний стек інструментів на Python (NLTK + gensim + PyTorch) і зробимо все інтерактивно прямо в браузері.

Що таке NLTK?

NLTK (Natural Language Toolkit) — це бібліотека для Python з інструментами для обробки тексту й природної мови. Це не одна мовна модель, а набір готових засобів для роботи з текстом.

За допомогою NLTK можна:

  • розбивати текст на слова й речення (токенізація);
  • знаходити та прибирати стоп-слова;
  • виконувати стемінг і лематизацію;
  • працювати з текстовими корпусами та частотами слів.

У цьому уроці ми:

  • Розіб’ємо текст на токени і приберемо «шум»
  • Зведемо слова до однієї форми (стемінг / лематизація)
  • Попрацюємо з реальним романом
  • Побачимо, як слова стають векторами
  • Порівняємо Word2Vec і GloVe та зрозуміємо embeddings
  • Розберемо мовні моделі, RNN, LSTM і Seq2seq
  • Побачимо, як працює transfer learning

Навіщо це в NLP? Моделі не можуть аналізувати сирий рядок як змістовні одиниці. Токенізація задає одиниці подальшої роботи — слова, частини слів або символи — для пошуку, класифікації та генерації.

3 Стоп-слова

Стоп-слова («the», «and», «is», «і», «та»…) зазвичай прибирають як часті слова, що мало допомагають у деяких задачах. Демонстрація підтримує базові англійський та український списки:

Навіщо це в NLP? У пошуку ключових слів чи тематичному аналізі вилучення частих службових слів може зменшити шум і підкреслити важливі терміни. Але для задач, де важливі заперечення або граматика (наприклад, «не сподобалось»), стоп-слова видаляють обережно або не видаляють зовсім. 

from nltk.corpus import stopwords
nltk.download('stopwords')

stop = set(stopwords.words('english'))

# → ['Cats', 'like', 'milk', 'dogs', 'like', 'bones']

4 Стемінг і лематизація

Слова study, studies, studying для комп’ютера різні, а за змістом — одне. Є два способи звести їх до однієї форми:

Навіщо це в NLP? Зведення словоформ допомагає пошуку знаходити «run» за запитом «running», а лічильнику частот — об’єднувати варіанти одного слова. Лематизація враховує словник і точніша, тоді як стемінг швидший, але грубіший.

Стемінг

Відрізає закінчення за простими правилами. Швидко, але результат може бути не словом (studies → studi).

Лематизація

Шукає словникову форму. Повільніше, але результат — справжнє слово (studies → study). 

from nltk.stem import PorterStemmer, WordNetLemmatizer
nltk.download('wordnet')

st = PorterStemmer()
lem = WordNetLemmatizer()

for w in ['studies', 'studying', 'mice']:
    print(w, st.stem(w), lem.lemmatize(w))
# studies  studi  study
# studying studi  studying
# mice     mice   mouse

Навіщо це в NLP? Корпус — це приклади мови, на яких досліджують закономірності та навчають або перевіряють моделі. Аналіз корпусу показує частоти слів і дає змогу порівнювати, як модель працює на різних текстах.

6 Embeddings: слова як числа

Комп’ютер працює з числами, тож кожному слову дають вектор — список координат. Схожі за змістом слова отримують близькі координати.

Навіщо це в NLP? Embeddings перетворюють слова на числові представлення, які модель може використовувати для обчислень. Вони передають інформацію про схожість слів і допомагають задачам класифікації, пошуку схожих текстів та аналізу значення слів у контексті.

Простий приклад: «Кіт їсть рибу»

Уявімо, що кожне слово перетворилося на вектор із трьох чисел. Щоб отримати один спрощений вектор для речення, усереднимо вектори його слів: 

кіт   → [0.8, 0.2, 0.1]
їсть  → [0.1, 0.9, 0.2]
рибу  → [0.7, 0.3, 0.8]

вектор речення = ([0.8, 0.2, 0.1] +
                  [0.1, 0.9, 0.2] +
                  [0.7, 0.3, 0.8]) / 3
                = [0.53, 0.47, 0.37]

Важливо: числа тут умовні — це лише наочна демонстрація. У справжніх моделях вектори мають набагато більше координат і навчаються на великій кількості текстів. Контекстні моделі також можуть створювати різні вектори для того самого слова залежно від речення. 

# pip install gensim
import gensim.downloader as api

w = api.load('glove-wiki-gigaword-50')
print(w['cat'][:5])                 # перші 5 чисел вектора
print(w.similarity('cat', 'dog'))   # ≈ 0.92
print(w.similarity('cat', 'car'))   # ≈ 0.32
print(w.most_similar('cat', topn=3))

Схожість слів (симуляція GloVe)

Word2Vec vs GloVe

Word2Vec

Грає у «вгадай сусіда»: бачить маленьке вікно слів і вчиться вгадувати слово за оточенням (або навпаки).

GloVe

Спершу рахує, як часто слова трапляються поряд у всьому тексті, а потім стискає ці підрахунки у вектори. 

# GloVe: арифметика слів
print(w.most_similar(positive=['king', 'woman'], negative=['man'], topn=1))
# → [('queen', 0.85...)]

# Word2Vec: тренуємо на «Еммі»
from gensim.models import Word2Vec
sents = [[x.lower() for x in s] for s in gutenberg.sents('austen-emma.txt')]
m = Word2Vec(sents, vector_size=50, window=5, min_count=5)
print(m.wv.most_similar('emma', topn=3))

Важливо: king − man + woman ≈ queen. Модель, навчена лише на одному романі (~190 тис. слів), значно слабша за GloVe, який «читав» мільярди слів.

7 Найпростіша мовна модель

Мовна модель оцінює ймовірність послідовності або передбачає наступний токен: «що найімовірніше буде далі?». Біграмна модель рахує пари сусідніх слів. Вона проста, але не пам’ятає далекий контекст:

Навіщо це в NLP? Передбачення наступного слова лежить в основі автодоповнення, генерації тексту й оцінювання того, наскільки фраза схожа на природну мову. Біграми — простий спосіб побачити цю ідею до переходу до нейромереж. 

clean = [x.lower() for x in words if x.isalpha()]
cfd = nltk.ConditionalFreqDist(nltk.bigrams(clean))

print(cfd['miss'].most_common(3))
# [('woodhouse', 47), ('bates', 25), ('fairfax', 17)]

word = 'emma'
out = [word]
for _ in range(10):
    word = cfd[word].max()
    out.append(word)
print(' '.join(out))
# emma was the only person ...

8 LSTM (Long Short-Term Memory)

Рекурентна мережа читає речення слово за словом і після кожного оновлює «пам’ять» (вектор h). Проблема: на довгих реченнях початок поступово забувається.

LSTM лікує це так: поруч із короткою пам’яттю h вона має довгу пам’ять c (як стрічка конвеєра). Три «ворота» вирішують, що викинути, що записати і що показати.

Навіщо це в NLP? LSTM створювали, щоб моделі краще враховували порядок і довший контекст у послідовностях. Її застосовували для мовного моделювання, класифікації тексту та генерації; це також корисний крок до розуміння сучасніших архітектур. 

import torch, torch.nn as nn

emb = nn.Embedding(1000, 16)   # словник 1000 → вектори 16
lstm = nn.LSTM(16, 32, batch_first=True)

ids = torch.tensor([[5, 42, 7, 99]])   # 1 речення з 4 слів
out, (h, c) = lstm(emb(ids))
print(out.shape, h.shape, c.shape)
# torch.Size([1, 4, 32])  torch.Size([1, 1, 32])  torch.Size([1, 1, 32])

9 RNN і Seq2seq: послідовність у послідовність

Канонічна RNN обробляє елементи по черзі й передає прихований стан h від кроку до кроку: hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁). Це враховує порядок слів, але звичайній RNN складно зберігати залежності на великій відстані. LSTM додає стан пам’яті c і ворота, які керують збереженням та оновленням інформації.

Навіщо це в NLP? RNN і Seq2seq дають змогу моделювати впорядкований текст і перетворювати одну послідовність на іншу — наприклад, перекладати речення, узагальнювати текст або генерувати символи.

Seq2seq — це схема «послідовність на вході → послідовність на виході». Наприклад, encoder читає речення, а decoder крок за кроком створює переклад. Encoder і decoder можуть бути RNN або LSTM; у сучасних системах часто використовують трансформери.

Encoder

Читає вхідну послідовність і формує її представлення.

Decoder

Використовує представлення, щоб передбачити вихідні токени по одному. 

# Схема навчання символьної RNN: передбачити наступний символ
import torch.nn as nn

# input_ids і зсунуті на 1 target_ids: [batch, довжина]
vocab_size = 100  # кількість символів у словнику
embedding = nn.Embedding(vocab_size, 32)
rnn = nn.GRU(32, 64, batch_first=True)
output = nn.Linear(64, vocab_size)

x = embedding(input_ids)
hidden, _ = rnn(x)
logits = output(hidden)  # оцінка кожного можливого наступного символу
loss = nn.functional.cross_entropy(
    logits.reshape(-1, vocab_size),
    target_ids.reshape(-1)
)

У навчальних даних ціль зсувають на один символ: для рядка привіт модель бачить приві і вчиться передбачити ривіт. Під час генерації останній передбачений символ додають до входу й повторюють крок.

А як працює трансформер?

Трансформер використовує механізм self-attention: кожен токен може враховувати інші токени послідовності. На відміну від RNN, він обробляє позиції паралельно під час навчання; позиційне кодування додає інформацію про порядок.

10 Transfer learning

Transfer learning — використання знань моделі, навченої раніше на великому наборі даних, для нової задачі. Це зазвичай потребує менше розмічених прикладів і часу, ніж навчання з нуля.

Навіщо це в NLP? Навчання мовної моделі з нуля потребує багато тексту й обчислень. Transfer learning дозволяє використати вже засвоєні мовні закономірності й адаптувати модель до вузької задачі, наприклад класифікації відгуків або відповідей на запитання.

  1. Завантажте попередньо навчені embeddings або мовну модель.
  2. Використайте їх як незмінні ознаки для нового класифікатора.
  3. За потреби донавчіть частину моделі на своїх даних (fine-tuning).

Заморожені ознаки

Попередньо навчені параметри не змінюються; навчається лише новий шар. Швидше й потребує менше даних.

Fine-tuning

Частина або всі параметри донавчаються на цільовій задачі. Може дати кращий результат, але потребує обережного налаштування. 

# Приклад використання готових GloVe-векторів як ознак
